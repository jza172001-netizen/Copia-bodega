## Descripción

## Qué problema resuelve

Una pulidora sale con su maleta, su llave y sus discos. Antes la app solo tenía una marca de *"lleva accesorios"* y una nota de texto libre: se podía registrar **"incompleta"** pero no **qué** faltó — así que no había con qué reclamarle nada a nadie.

Los accesorios **no son todos iguales**, y la diferencia es de negocio, no de forma:

- **Retornable** (maleta, llave, cargador): sale y vuelve **con** la herramienta. No mueve stock; se revisa al devolverla.
- **Consumible** (disco, broca): es un ítem del inventario con su **propio stock**. Sale pegado a la herramienta, descuenta, se gasta y **no vuelve**.

Por eso la columna es `jsonb` y no una lista de texto: una lista plana no podía distinguirlos, que es justo lo que impedía descontar un disco o reclamar una llave.

## Cambios

**Base de datos** (`supabase/migrations/20260905140000_add_accessories_to_items.sql`, aplicada)
```json
{ "nombre": "Maleta" }                                  → retornable
{ "nombre": "Disco", "itemId": "…", "cantidad": 2 }     → consumible
```

**`components/AccessoriesEditor.tsx`** (nuevo) — editor de la lista en crear y editar ítem, solo para herramienta. Los consumibles se enganchan a un ítem existente del inventario, indicando cuántos salen por cada herramienta.

**`App.tsx`** — al despachar, el lote se expande con los accesorios consumibles: 2 pulidoras se llevan 2 juegos de discos. Se hace **en un solo lugar** y no en cada pantalla, así lo respetan por igual el chatbot, el asistente de despacho y el formulario directo.

**`components/ReturnToolModal.tsx`** — lista de revisión de los retornables. Arrancan **todos marcados** (lo normal es que vuelva completa, así solo se desmarca lo que falta). Al desmarcar algo, el estado pasa **solo** a "incompleta", y lo faltante queda **escrito con nombre**: `Faltó: Llave.`

## Verificación

`npm run lint` y `npm run build` pasan.

De punta a punta en el navegador, con una pulidora que lleva maleta, llave y 2 discos:

```
  OK  sale la pulidora COMO PRÉSTAMO
  OK  los DISCOS salen con ella, como gasto
      -> Disco de corte x2 prestamo=false | Pulidora (Verde · Bosch) x1 prestamo=true
  OK  salieron 2 discos (los que lleva la pulidora)
  OK  el stock de discos bajó de 20 a 18
  OK  la devolución pregunta si volvió con todo
  OK  lista la maleta y la llave
  OK  NO lista el disco (se gastó, no vuelve)
  OK  al desmarcar la llave, marca "Incompleta" solo
  OK  queda ESCRITO qué faltó  ->  "Faltó: Llave."
```
