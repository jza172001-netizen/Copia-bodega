## Descripción

## Causa raíz

`lib/supabase.ts` llamaba `createClient(url, key)` a nivel de módulo. El proyecto `bodega-inventario.vercel.app` no tiene las variables de entorno configuradas → Supabase lanzaba `Error: supabaseUrl is required.` → React nunca montaba → pantalla blanca.

## Cambios

- **`lib/supabase.ts`**: solo crea el cliente si `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY` están presentes. Si no, exporta `null` y la app cae automáticamente a modo localStorage (todos los db calls en App.tsx ya tienen `.catch(() => {})`).
- **`index.tsx`**: agrega `ErrorBoundary` que captura cualquier crash de render y muestra mensaje + botón "Limpiar cache y recargar" en lugar de pantalla blanca.
